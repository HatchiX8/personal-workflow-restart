# Frontend Module Focus

確認 UI／route／feature 入口、component 階層、props、events、slots、callbacks、local／store／server state、API client、query／mutation／cache、routing、permission 及 loading／empty／error／disabled 狀態。

輸出必須清楚標出模組擁有與可修改的 UI、component、composable、store 或 style 範圍，以及不可任意修改的 shared component、global store、API client、route contract。讀取 shared 區域時只確認 contract，不擴大成 shared layer 分析。
