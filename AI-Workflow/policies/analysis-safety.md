# 分析角色共用安全政策

## 唯讀原則

- 分析任務不得修改程式碼、設定、資料庫、dependency、Git index 或 repository 狀態。
- 不得執行會產生或改變專案產物的命令。
- 可以使用唯讀的檔案列舉、文字搜尋、內容讀取與 Git 狀態查詢。
- 無法確認命令是否唯讀時，不得執行。

## 讀取範圍

- 優先讀取任務 Scope 內的代表性檔案。
- 不得無限制遍歷 vendor、dependency、build artifact、generated file 或 archive。
- 大型專案或模組必須採取取樣或切片，不得以完整深讀作為預設行為。
- 需要超出 Scope 才能完成分析時，必須停止或回報需要擴大範圍。

## 停止

遇到下列情況必須停止或縮小分析範圍：

- 任務要求修改專案狀態。
- 必要 Scope、Project 或 Module 無法唯一確認。
- 分析必須依賴禁止讀取的 private 資料。
- 專案規模超出角色規則允許的分析深度。

停止時必須回報原因，並提出可安全執行的替代分析範圍。
