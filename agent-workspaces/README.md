# Agent Workspaces

本資料夾用於保存不同專案的 agent workspace 樣板。

每個 project workspace 建議包含：

- `project-context.md`：保存專案地圖、技術棧、入口、重要模組與上手資訊。
- `team-style.md`：保存團隊工程風格、命名規則、檔案分層與常見開發慣例。

## 預設結構

```txt
agent-workspaces/
├─ project-a/
│  ├─ project-context.md
│  └─ team-style.md
└─ project-b/
   ├─ project-context.md
   └─ team-style.md
```
