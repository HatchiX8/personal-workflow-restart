# Developer 輸出規則

## 正式執行結果

唯讀分析只在對話中回覆已確認行為、來源路徑、結構推論與待確認事項，不得建立 md 報告，
並須明確說明本次未修改檔案。開發任務必須保留足以產生完成回覆的下列執行結果：

- 修改了哪些檔案。
- 完成了哪些需求。
- 已執行的驗證與結果。
- 無法執行的驗證、原因與建議指令。
- 是否有未完成事項。
- 是否有需要人工確認的風險。

## 對話完成回覆

完成回覆應依任務規模保持精簡，至少包含：

- 完成內容。
- 主要修改檔案或範圍。
- 驗證方式與結果。

若驗證失敗、關鍵驗證無法執行、只完成部分需求，或發現重大 contract、資料、權限風險，必須
明確說明。沒有風險、限制或未完成事項時，不建立空泛區塊。
